MITS Kundenhinweise

Installationsanleitung

Diese Anleitung beschreibt die Installation und Ersteinrichtung von MITS Kundenhinweise in der modified eCommerce Shopsoftware. Die Installation kommt ohne manuellen SQL-Import und ohne Änderungen an Core-Dateien aus.

1. Systemüberblick

MITS Kundenhinweise zeigt frei konfigurierbare Hinweise im Shop an. Inhalte, Darstellungsart, Zeitraum, Zielgruppen und Seiten können unabhängig voneinander eingestellt werden.

  • Hinweisbox, wichtiger Hinweis, Top-Bar, Modal/Popup und Toast
  • mehrsprachige Inhalte mit optionaler Frontend-Überschrift
  • Moduloberfläche in Deutsch, Englisch, Französisch, Italienisch, Spanisch, Niederländisch und Polnisch
  • Zeitsteuerung, Countdown und unterschiedliche Anzeigehäufigkeiten
  • Filter nach Seiten, Kundengruppen, Kunden, Ländern, Newsletterstatus sowie Kategorie-, Artikel- und Hersteller-IDs
  • automatische oder manuelle Platzierung im Shoptemplate
  • updatesichere Template-Overrides
  • optionale Migration des alten Fremdmoduls customers_notice
Keine Core-Änderungen: Die Installation erfolgt über die normalen Erweiterungspunkte der modified Shopsoftware.

2. Voraussetzungen

  • modified eCommerce Shopsoftware ab Version 2.0.6.0
  • PHP 8.x
  • funktionierender Admin-Zugang
  • Dateizugriff per FTP, SFTP oder Hosting-Dateimanager
  • JavaScript im Browser für automatische Platzierung, Modal/Toast, Countdown und Drag & Drop

Unterstützte Shoptemplates

Das Modul ist nicht auf ein einzelnes Template fest verdrahtet. Die folgenden verbreiteten Templates sind bei der vorgesehenen Standardintegration berücksichtigt:

Auch eigene oder weitere modified-Templates können verwendet werden. Falls die automatische Position nicht passt, kann pro Hinweis ein eigener CSS-Selektor eingetragen oder die manuelle Smarty-Platzierung verwendet werden.

3. Vor der Installation: Backup

Erstellen Sie vor der Installation eine aktuelle Sicherung von Shopdateien und Datenbank.

Auch wenn das Modul keine Core-Dateien ersetzt und seine eigenen Tabellen automatisch anlegt, sollte eine neue Erweiterung zuerst mit einem aktuellen Backup installiert werden.

4. Datei-Upload

  1. Entpacken Sie das Modularchiv lokal.
  2. Öffnen Sie den enthaltenen Ordner shoproot.
  3. Kopieren Sie den kompletten Inhalt von shoproot in das Hauptverzeichnis Ihres Shops.
  4. Bestätigen Sie das Zusammenführen vorhandener Verzeichnisse.
Umbenanntes Adminverzeichnis: Wenn Ihr Shop nicht den Ordner admin verwendet, kopieren Sie den Inhalt von shoproot/admin in Ihr tatsächliches Adminverzeichnis.

Es wird keine vorhandene Shop-Core-Datei überschrieben. Die Dateien des Moduls liegen in eigenen Modul- und Extra-Verzeichnissen.

5. Systemmodul installieren

  1. Melden Sie sich im Adminbereich an.
  2. Rufen Sie Module > System Module auf.
  3. Wählen Sie MITS Kundenhinweise.
  4. Installieren bzw. aktivieren Sie das Modul.

Das Modul legt die benötigten Datenbanktabellen und Konfigurationseinträge automatisch an. Ein SQL-Import per phpMyAdmin ist nicht notwendig.

CSRF-Schutz: Schreibende Admin-Aktionen verwenden das CSRF-System der modified Shopsoftware. Ist das CSRF-System im Shop aktiviert, werden die Tokens automatisch von modified erzeugt und geprüft.

6. CSS- und JavaScript-Einbindung

Im Systemmodul stehen drei Betriebsarten zur Auswahl.

ModusGeeignet fürVerhalten
externaldie meisten ShopsCSS und JavaScript werden automatisch als cachefähige Moduldateien geladen.
manualoptimierte Templates mit eigener DateikombinierungDas Modul bindet keine Assets selbst ein. CSS und JavaScript werden durch das Shoptemplate geladen und können dort kombiniert bzw. komprimiert werden.
inlineSonderfälleCSS und JavaScript werden direkt in die HTML-Seite geschrieben. Zusätzliche Requests entfallen, die Dateien können aber nicht separat vom Browser gecacht werden.
Empfehlung: Verwenden Sie external, wenn Sie keine spezielle Asset-Bündelung im Template einsetzen. Bei einem optimierten Template mit eigener Komprimierung ist manual meist die bessere Wahl.

Manuelle CSS-Einbindung

Kopieren Sie zuerst die Moduldatei

includes/external/mits_customers_notice/css/mits_customers_notice.css

nach

templates/<DEIN_TEMPLATE>/css/mits_customers_notice.css.

Danach kann die Datei bei modified-Templates mit general_bottom.css.php vor dem vorhandenen $css_min-/Komprimierungsblock ergänzt werden:

if (is_file(DIR_FS_CATALOG . DIR_TMPL_CSS . 'mits_customers_notice.css')) {
    $css_array[] = DIR_TMPL_CSS . 'mits_customers_notice.css';
}

Manuelle JavaScript-Einbindung

Kopieren Sie zuerst

includes/external/mits_customers_notice/js/mits_customers_notice.js

nach

templates/<DEIN_TEMPLATE>/javascript/mits_customers_notice.js.

In general_bottom.js.php kann vor dem vorhandenen $script_min-/Komprimierungsblock ergänzt werden:

if (is_file(DIR_FS_CATALOG . DIR_TMPL_JS . 'mits_customers_notice.js')) {
    $script_array[] = DIR_TMPL_JS . 'mits_customers_notice.js';
}

Damit werden beide Dateien zusammen mit den übrigen Template-Dateien über die vorhandene modified-Komprimierung verarbeitet.

Hinweis zu DIR_WS_BASE: In den Arrays von general_bottom.css.php und general_bottom.js.php werden relative Template-Pfade verwendet. DIR_WS_BASE wird von modified erst bei der späteren Ausgabe von href bzw. src vorangestellt.

7. Shoptemplate und Template-Overrides

Das Modul bringt eigene Standardvorlagen mit:

  • notice.html – normaler Hinweis
  • important.html – wichtiger Hinweis
  • topbar.html – Hinweisleiste
  • modal.html – Modal/Popup
  • toast.html – schwebender Toast

Die Standarddateien liegen unter:

includes/external/mits_customers_notice/templates/module/

Updatesichere Anpassungen können im aktiven Shoptemplate angelegt werden:

templates/<DEIN_TEMPLATE>/module/mits_customers_notice/

Eine dort vorhandene Datei mit gleichem Namen hat automatisch Vorrang vor der Modulvorlage. Im Adminbereich werden nur tatsächlich vorhandene .html-Vorlagen im Dropdown angeboten.

CSS-Override

Für eine eigene Gestaltung kann zusätzlich folgende Datei im aktiven Template angelegt werden:

templates/<DEIN_TEMPLATE>/css/mits_customers_notice.css

Manuelle Position im Template

Wird bei einem Hinweis die Platzierung Manuell per Smarty gewählt, steht der gerenderte Inhalt über folgende Variable zur Verfügung:

{$MITS_CUSTOMERS_NOTICE}

8. Optional: Altes Fremdmodul migrieren

Wenn die alten Tabellen customers_notice und customers_notice_description vorhanden sind, erkennt MITS Kundenhinweise die importierbaren Einträge automatisch.

  1. Installieren Sie zuerst MITS Kundenhinweise.
  2. Öffnen Sie Kunden > MITS Kundenhinweise.
  3. Öffnen Sie die angebotene Migrationsvorschau.
  4. Prüfen Sie Titel, Darstellungsart und eventuell markierte Sondertemplates.
  5. Starten Sie erst danach den Import.
  6. Prüfen Sie die importierten Hinweise im Frontend.
  7. Deaktivieren Sie anschließend die Frontend-Ausgabe des alten Fremdmoduls.
Die Migration ist nicht destruktiv. Die alten Tabellen werden weder geändert noch gelöscht. Bereits importierte Legacy-IDs werden bei einem erneuten Import übersprungen.

9. Empfohlener Funktionstest

  1. Erstellen Sie unter Kunden > MITS Kundenhinweise einen neuen Testhinweis.
  2. Vergeben Sie einen eindeutigen internen Titel.
  3. Tragen Sie einen kurzen Inhalt in der gewünschten Sprache ein.
  4. Wählen Sie zunächst Hinweis, Automatisch und Immer anzeigen.
  5. Beschränken Sie den Test unter Seiten z. B. auf die Startseite.
  6. Aktivieren und speichern Sie den Hinweis.
  7. Rufen Sie die betreffende Shopseite in einem privaten Browserfenster auf.

Prüfen Sie danach bei Bedarf zusätzlich:

  • Schließen und Anzeigehäufigkeit
  • Start- und Endzeit
  • Modal oder Toast
  • Toast-Position auf Desktop und Smartphone
  • Button-Darstellung und Linkziel
  • Kundengruppen- und Seitenfilter

10. Update und Deinstallation

Update

  1. Erstellen Sie ein aktuelles Backup.
  2. Kopieren Sie den Inhalt des neuen Ordners shoproot über die vorhandenen Moduldateien.
  3. Rufen Sie Module > System Module auf.
  4. Wählen Sie MITS Kundenhinweise.
  5. Führen Sie die angebotene Modulaktualisierung aus.

Fehlende Datenbankfelder und neue Moduleinstellungen werden von der Update-Routine automatisch nachgezogen.

Deinstallation

Beim normalen Entfernen des Systemmoduls werden die Modulkonfiguration und das Adminrecht entfernt. Die drei MITS-Datentabellen bleiben absichtlich erhalten, damit angelegte Kundenhinweise bei einer späteren Neuinstallation nicht verloren gehen.

Nach der Deinstallation erscheint im Bereich Module > System Module der rote Button MITS Kundenhinweise komplett vom Server entfernen. Damit werden die mitgelieferten Moduldateien automatisch aus dem Shop entfernt.

Eigene Anpassungen bleiben erhalten: Selbst angelegte Template-Overrides sowie im Modus manual in das aktive Template kopierte CSS-/JavaScript-Dateien werden nicht automatisch gelöscht. So gehen individuelle Template-Anpassungen nicht versehentlich verloren.
